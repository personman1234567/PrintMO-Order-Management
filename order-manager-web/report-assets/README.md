# Report assets

Print-MO and Dr. Dallas logos were extracted from the owner-supplied redesigned PDF for the internal reporting pilot. The PDF is the visual authority; its fictional rates are not financial rules.

Manrope is reused from the Designer loading assets under the accompanying SIL Open Font License. Pinned browser libraries and upstream license notices live in vendor/; manifest.json records versions and checksums. The fontkit npm package declares MIT in its README (included unchanged). Libraries load only when reports are generated or previewed. No CDN or external document viewer is used.
